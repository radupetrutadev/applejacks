# assets/locations

The two storefront photographs for the "Două case / Two rooms" block.

## Drop them in

| filename | which shop | how to spot it |
|---|---|---|
| `mihai-viteazul.jpg` | **Apple Jacks daily** — Strada Mihai Viteazul 15 | portrait; wooden crate wall, the apple sign over the door, chalkboard reading "DACĂ…" |
| `traian-lalescu.jpg` | **Apple Jacks Coffeeholic** — Strada Traian Lalescu 19 | landscape; the house with the green `coffeeholic` awning and the terrace deck |

`.jpeg`, `.png` and `.webp` work too — the page tries those in turn if the
`.jpg` is not there. The file does need *an* extension, so rename anything
that came off a phone or a download as `unnamed`.

Any reasonable size is fine; the cards crop to 4:3 with `object-fit: cover`,
so keep the shopfront near the centre. ~1600 px on the long edge is plenty.

## If neither file is present

The card renders a generated two-ink plate instead. The layout never breaks
and no broken-image icon ever appears — so the site is safe to deploy before
the photos land.

## How they are treated

Desaturated, washed in red ink and pressed with the same grain as the paper,
so they sit inside the risograph look rather than fighting it. Hover lifts the
ink and gives the photograph back in full colour.
