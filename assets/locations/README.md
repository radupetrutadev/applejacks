# assets/locations

The two storefront photographs used in the "Două case / Two rooms" block.
Drop them in with **these exact filenames** — nothing else needs to change:

| file | which shop |
|---|---|
| `mihai-viteazul.jpg` | Apple Jacks daily — Strada Mihai Viteazul 15 (the entrance with the wooden crate wall and the chalkboard) |
| `traian-lalescu.jpg` | Apple Jacks Coffeeholic — Strada Traian Lalescu 19 (the street view of the pink building with seating outside) |

Any reasonably large landscape or portrait JPEG works; the cards crop to 4:3
with `object-fit: cover`, so keep the shopfront near the centre. Around
1600 px on the long edge is plenty.

Until a file is present, the card falls back to a generated two-ink plate —
the layout never breaks and no broken-image icon ever shows.

Photos are shown as they are, with no colour filter; hovering the card zooms
in slightly.
